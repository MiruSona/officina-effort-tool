# v15 코드 1판 피드백 (2026-10-03)

서브에이전트 한 판(게임 저장소 v15 코드 1판)을 `mark start` / `mark stop` 으로 쟀다.

- **잘 된 것** : `mark start` 가 바로 자기 기록 파일(agent-…)을 묶어 줘서 따로 할 일이 없었다. `mark show` 로 도는 중 값을 본 것도 편했다.
- **헷갈린 것** : 소단계(1~4)마다 mark 를 따로 열지 않고 한 판 전체 하나만 열었다. 소단계 「실제」 칸을 채우려면 소단계마다 mark 를 여닫아야 하는데, 한 판 안에서 겹치지 않게 여닫는 예시가 README 에 있으면 좋겠다.

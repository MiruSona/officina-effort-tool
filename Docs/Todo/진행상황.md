## 지금 상태

- 첫 판 소단계 1~12, 분류 개선 소단계 1~10 다 끝났다. **시험 128개 통과**, `gofmt`·`go vet` 깨끗.
- 실제 `~/.claude/projects` 로 실측했다 : 세션 106개 · 작업 1159건.
- `cost-state` 검산을 손으로 맞췄다 (세션 `0240547a` : 작업 합 790.7K / 총계 791.6K = 100%).
- **분류 개선 실측 : 미분류 75% → 8%** (87/1159). 이어받기 435 · 대화 236 · 도구실행 167 · 잡무 38.
- **빠진 규칙 종류 자동 덧붙이기**를 넣었다. 옛 `rules.txt` 에 `tool`·`runpre`·`runin`·`chore` 가
  한 줄도 없으면 `scan` 이 날짜 머리말과 함께 기본 줄만 끝에 더한다. 사람이 쓴 줄은 안 건드린다.
- **크기 배율을 실측으로 다시 잡았다** : `S/M/L/XL` = **0.3 / 1.0 / 2.4 / 5.0**.
- 낱말 규칙 12줄(`mem` 명령·모니터링·compact·남은일·goldenset·짧은 대화)과 접두 `Agent 도구로` 를 더했고,
  곁도구(`SendMessage`·`ToolSearch`·`AskUserQuestion`·`Monitor`·`TaskStop`·`ListAgents`)는 도구 셈에서 뺐다.
  웹조사 판정에서는 셸을 예외로 허용한다.

  정확히 짝지을 수 있는데 실물을 아직 못 봤다.

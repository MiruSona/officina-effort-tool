## 걸린 것

- `estimate 조사:M 구현:L 검증:M` 이 **「모르는 분류 "M"」** 으로 종료했다.
  소단계 꼴이 `[이름:]분류[:크기]` 라 `조사:M` 은 「이름 조사 · 분류 M」으로 읽힌 것이다.
  README 에는 바르게 적혀 있지만, **칸이 둘일 때 뒤를 크기로 보는 것이 먼저 떠오른다.**
  오류 줄에 「크기를 주려면 `조사:조사:M` 처럼 분류를 먼저 적는다」 한 줄이 붙으면 한 번에 고칠 수 있겠다.

## 잘 된 것

- 고쳐서 `estimate "조사:조사:M" "배선구현:구현:L" "검증:검토:M"` 을 치니 바로 표가 나왔다.
  근거 칸의 `실측 n=195` 로 표본 수가 보여 믿을 만큼만 믿었다.

# 주방 기구 시안 작업 피드백 (ProjectMozzi2 · 2026-10-05)

## 잘 된 것

- `mark start` → `mark stop` 이 서브에이전트 기록을 바로 묶었고 「기록 구간 11분」이 한 줄로 나왔다.

## 헷갈린 것

- `estimate 조사:S 구현:M` 이 합 5분(범위 1~25분)을 냈는데, 맡긴 쪽 어림은 20~30분이었다. 그림 뽑기처럼 **기다림이 많은 일**은 「구현」 분류 표본과 결이 다르다 — 「그림뽑기」 같은 분류나 `--note pixellab` 로 표본을 가를 수 있으면 좋겠다.
- `mark start` 를 문서 읽기 뒤에 쳐서 앞쪽 몇 분이 빠졌다. 서브에이전트 첫 도구 시각부터 재는 선택(`mark start --from-first-tool`)이 있으면 늦게 쳐도 맞는다.

## 반복 07 주방 정식 그림 (2026-10-05 · 같은 날 뒷판)

- 대화 문맥이 꽉 차 요약되고 이어진 판에서, 열어 둔 mark(`2-서랍장`)가 요약 앞뒤를 통째로 묶어 34분이 됐다. 그 안에는 서랍장 말고 배경 · 찜기 · 떡메 뽑기가 다 들었다. 요약(compact) 때 열린 mark 를 알려 주거나 자동으로 끊어 주면 소단계가 섞이지 않는다.
- `mark stop` 결과가 「기록 구간 = 공수 표 실제 칸」이라고 바로 알려 줘서 표 쓰기가 쉬웠다.

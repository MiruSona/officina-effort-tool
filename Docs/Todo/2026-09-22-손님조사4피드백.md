# EffortTool 피드백 — 손님 그림 레퍼런스 조사 4 (2026-09-22)

조사 서브에이전트 한 판에서 `estimate` 만 썼다. 막힌 것 한 가지를 남긴다.

## 막힌 것 — `estimate` 인자 꼴을 세 번 틀렸다

`effort estimate "손님 그림 레퍼런스 웹 조사와 조사 문서 쓰기"` 로 시작했더니
**「모르는 분류 "…"」** 만 나왔다. 그다음 `문서읽기:S` 로 고치니 **「모르는 분류 "S"」** 가 나왔다.
결국 `--help` 와 `rules.txt` 를 직접 열어 보고서야 **`<분류>:<크기>`** 이고
분류는 `rules.txt` 의 `word` 표에 있는 낱말(조사 · 설계 · 구현 · 실측 · 문서 · 검토)뿐이라는 것을 알았다.

- 「모르는 분류 "S"」 는 특히 헷갈렸다. `S` 는 크기 자리에 있었는데 분류로 읽혔다
  — **콜론 앞뒤를 뒤집어 쓴 것**을 알려 주면 한 번에 고쳤을 것이다.
- 바라는 것 : 오류 줄에 **쓸 수 있는 분류 목록**과 **`조사:M` 같은 올바른 보기**를 같이 찍어 주면 좋겠다.

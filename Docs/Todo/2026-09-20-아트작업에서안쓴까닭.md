# 아트 작업에서 EffortTool 을 안 쓴 까닭 (2026-09-20)

게임 저장소(ProjectMozzi2)에서 찹쌀이 그림·점프 애니를 서브에이전트 4판으로 만든 작업의 피드백이다.
**이번에 EffortTool 을 한 번도 안 썼다.** 공수 표의 「실제」 칸은 서브에이전트 실행 시간을 눈으로 보고 적었다.

## 왜 안 썼나

| 까닭 | 자세히 | 제안 |
| --- | --- | --- |
| 스킬이 세션 시작 때 목록에 안 뜬다 | `effort-usage` 는 `Tools/EffortTool/README.md` 를 한 번 읽어야 목록에 뜬다. 아트 작업은 README 를 읽을 일이 없어 끝까지 안 떴다 | 세션 시작 훅이 **한 줄로 일깨워 준다** (예 : 「공수는 `effort estimate` · `effort list` 로 잰다」). 훅 하나가 규칙 문서보다 확실했다 (게임 저장소 실측) |
| 문맥 압축 뒤에는 더 잊는다 | 판이 4개라 중간에 문맥이 끊겼고, 그 뒤로는 툴이 있다는 것 자체가 기억에서 빠졌다 | 위와 같다 — 훅이 매 세션 앞에 두면 압축과 무관하다 |
| 서브에이전트가 한 일의 「실제」를 재는 길이 불분명하다 | 일을 한 것은 서브에이전트고 시간을 아는 것은 메인 세션이다. 에이전트 duration 을 `effort` 에 넣는 길(뒤늦게 실제값만 적기 · 시작/끝 시각으로 적기)이 있는지 몰라 그냥 손으로 적었다 | README 나 스킬에 **「서브에이전트가 한 일의 실제 시간을 넣는 법」** 한 절을 넣는다. 없으면 `effort done --actual <분>` 같은 꼴을 만든다 |

## 메모

- 이렇게 손으로 적으면 **「어림하지 않는다」는 게임 저장소 규칙(`AGENTS.md` 1-1)을 못 지킨다.** 위 셋 중 첫째(훅 한 줄)만 되어도 이번 작업은 툴로 쟀을 것이다.

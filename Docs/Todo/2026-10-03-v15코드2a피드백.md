# v15 코드 2a 피드백 (ProjectMozzi)

> 2026-10-04 · 서브에이전트 한 판에서 `mark start/stop` 을 소단계마다 여섯 번 찍은 기록.

## 잘 된 것

- 소단계마다 `mark stop <id>` → 바로 다음 `mark start` 로 이어 찍어도 묶기가 한 번도 안 어긋났다 (`묶기모호` 0).
- 기록 구간과 찍은 구간이 늘 같게 나와 공수 표 「실제」 칸을 그대로 옮겨 적었다.

## 헷갈린 것

- 분 단위로만 나와 2~4분짜리 소단계는 반올림 차이가 크다. 짧은 판이 많을 때 `mark stop` 에 초 단위(또는 소수 분)를 같이 보여 주면 눈금 잡기에 좋겠다.

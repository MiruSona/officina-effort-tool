# ProjectMozzi 사용 피드백 (2026-09-20)

게임 저장소 ProjectMozzi2 의 이날 세션 기록이다. **이번 세션은 공수를 `effort` 로 재지 않았다.** 왜 안 쓰게 됐는지를 적는다.

## 막힌 것 (안 쓰게 된 까닭)

| 무엇 | 자세히 |
| --- | --- |
| 스킬이 뜰 계기가 없었다 | 스킬 `EffortTool:effort-usage` 는 세션 시작 때 목록에 안 뜨고 `Tools/EffortTool/README.md` 를 읽어야 뜬다. 그런데 메인 세션은 「직접 손대지 않고 서브에이전트에게 맡긴다」는 규칙이라 README 를 읽을 계기가 없었다 |
| 「실제」 칸을 다른 값으로 채웠다 | 공수 표의 「실제」 칸은 서브에이전트 실행 시간(duration)과 빌드 로그 초로 대신 적었다. 규칙(어림 금지)에는 어긋난다 |

## 헷갈린 것

| 무엇 | 자세히 |
| --- | --- |
| 서브에이전트가 한 일을 누가 재나 | 서브에이전트가 한 일의 시간을 메인 세션이 `effort` 로 어떻게 재야 하는지 — 서브에이전트가 재나, 메인이 시작 · 끝을 찍나 — 게임 저장소 규칙에서 바로 안 보였다 |

## 잘 된 것

- 이번 세션에는 쓰지 않아 적을 것이 없다.

## 바라는 것

- 세션 시작 훅에서 「공수 재기 : effort …」 한 줄 안내. `stage` · `mem` 훅처럼 세션을 열면 바로 보이게 한다.
- 서브에이전트에게 맡긴 작업을 재는 짧은 절차.

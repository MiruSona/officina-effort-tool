# 반복 07 농장 강화 피드백

> 2026-10-05 · 게임 저장소 반복 07 코드 갈래(서브에이전트 한 판)에서 `estimate` · `mark` 를 쓴 기록.

## 잘 된 것

- `mark start` 한 번에 묶은 기록 파일까지 찍어 줘 「제대로 묶였나」 를 바로 알았다. `mark show` 로 도중 값도 봤다.
- `estimate` 가 분류를 틀리게 주면(「시험」) 쓸 수 있는 분류 목록을 바로 보여 줬다.

## 헷갈린 것

- 소단계 일곱을 한 판 안에서 했는데 mark 를 하나만 걸어 소단계별 실제 값이 없다. mark 를 소단계마다 끊어 걸면 되지만 한 판 안에서
  start/stop 을 일곱 번 부르는 것이 번거롭다. `mark lap "<소단계>"`(지금 mark 안에 경계만 찍고 소단계별로 나눠 보여 주기)가 있으면 공수 표를 칸마다 채울 수 있다.
- `estimate` 의 `실측:M` 칸이 31분(범위 2분~4시간)으로 다른 칸보다 훨씬 크게 잡혀 합(54분)을 끌어올렸다. 실제 Play 확인은 10분 안이었다.

## 반복 07 주방 배선 (같은 날 · 코드 갈래 둘째 판)

- 잘 된 것 : 소단계마다 `mark start` / `mark stop` 을 따로 걸었더니 공수 표 칸을 모두 실측으로 채웠다 (다섯 번 끊음).
- 헷갈린 것 : `mark stop` 을 Git Bash 에서 `.\Tools/...` 꼴로 잘못 불러 한 번 헛돌았다 — 셸 탓이라 툴 문제는 아니다. 다만 stop 결과의 「기록 구간」이 1분 단위라 1분 안팎의 소단계(문서 읽기 · 검사)는 모두 「1분」 으로 뭉친다. 초 단위(또는 0.5분)로 보여 주면 짧은 소단계끼리 견줄 수 있다.
